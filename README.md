# 🌻 Flores Amarillas para Beatriz

Proyecto web romántico creado para abrirse directamente desde un teléfono.

## Archivos
- `index.html` — estructura de la página.
- `style.css` — diseño y animaciones.
- `script.js` — interacción, pétalos y efectos.

## Cómo publicarlo gratis
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `style.css` y `script.js`.
3. En Settings → Pages, selecciona la rama principal (`main`) y la carpeta `/root`.
4. GitHub generará un enlace público.
5. Envía ese enlace por WhatsApp.

No requiere instalación de ninguna aplicación para quien recibe el enlace.
